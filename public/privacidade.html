Workestra Tools

Política de Privacidade de Dados • Versão 3.0 (Vigência: Outubro de 2026)

Esta Política de Privacidade tem como objetivo informar de maneira transparente, detalhada e precisa como a plataforma web Workestra Tools (disponível no endereço eletrônico oficial https://workestratools.vercel.app) realiza a coleta, tratamento, armazenamento, proteção e descarte de dados pessoais dos seus usuários.

O Workestra Tools atua em estrita observância à legislação vigente de proteção de dados, notadamente a Lei Geral de Proteção de Dados Pessoais do Brasil (LGPD - Lei Federal nº 13.709/2018), o General Data Protection Regulation (GDPR - Regulamento UE 2016/679) e a Política de Dados do Usuário dos Serviços de API do Google (Google API Services User Data Policy).

2. Dados Pessoais Coletados e Finalidades do Tratamento

O Workestra Tools é um software educacional de música. Para permitir que o usuário salve suas próprias sequências de acordes e mantenha suas preferências em múltiplos aparelhos, oferecemos o login seguro via Google Identity / Google OAuth 2.0.

Dado Coletado Origem Finalidade Específica Base Legal (LGPD)
Nome e Sobrenome Conta Google (OAuth) Identificação visual do usuário e personalização da saudação de boas-vindas na tela. Consentimento (Art. 7º, I) / Execução de Contrato
Endereço de E-mail Conta Google (OAuth) Chave primária para vincular e recuperar o progresso, progressões de acordes e treinos musicais salvos pelo usuário. Consentimento (Art. 7º, I) / Execução de Contrato
Foto de Perfil (Avatar URL) Conta Google (OAuth) Exibição do avatar no botão de perfil no cabeçalho do aplicativo para indicar a conta autenticada. Consentimento (Art. 7º, I)
Identificador Único Google (UID) Google Identity Services Autenticação criptográfica no banco de dados e controle de segurança para que apenas o próprio usuário acerte suas progressões. Execução de Contrato / Legítimo Interesse

Nenhum dado sensível é coletado. Não coletamos, não solicitamos e não armazenamos senhas do Google, informações financeiras, números de documentos, dados biométricos ou localização geográfica precisa.

3. Dados de Uso Musical e Preferências Técnicas

Durante a utilização do aplicativo pelo usuário autenticado, são salvas no banco de dados em nuvem as seguintes informações técnicas e pedagógicas:

  • Progressões harmônicas, sequências de acordes e graus musicais criados pelo estudante;
  • Preferências de áudio (timbre de instrumento selecionado, ajustes de volume mestre e metrônomo);
  • Tema de interface visual selecionado (Modo Claro / Modo Escuro);
  • Histórico de pontuação e aproveitamento nos testes do módulo Quiz Auditivo.
Garantia de Não Comercialização de Dados: O Workestra Tools NÃO comercializa, NÃO aluga, NÃO vende, NÃO compartilha e NÃO disponibiliza dados pessoais ou de uso com corretores de dados, redes sociais, ferramentas de rastreamento ou empresas de publicidade sob nenhuma hipótese.

4. Conformidade Rigorosa com a Política do Google (Google API User Data Policy)

Declaração Obrigatória de Uso Limitado (Limited Use Disclosure):

"Workestra Tools' use and transfer of information received from Google APIs to any other app will adhere to Google API Services User Data Policy, including the Limited Use requirements."

(Em português: O uso e a transferência pelo Workestra Tools de informações recebidas das APIs do Google para qualquer outro aplicativo estarão em conformidade com a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.)

Especificamente, garantimos que:

  1. Não utilizamos os dados obtidos através das APIs do Google para criar, treinar ou aprimorar modelos de inteligência artificial ou aprendizado de máquina (Machine Learning) generalistas.
  2. Não transferimos nem divulgamos dados de usuários a terceiros, exceto provedores estritamente necessários para a prestação do serviço de infraestrutura técnica (Google Firebase).
  3. Nenhum colaborador ou ser humano lê ou acessa os dados pessoais dos usuários, a menos que autorizado expressamente para suporte técnico ou exigido por lei.

5. Compartilhamento e Infraestrutura de Terceiros

Para a operacionalização segura da plataforma, utilizamos apenas provedores de infraestrutura técnica de renome global:

  • Google Firebase & Google Cloud Platform: Gerenciamento da autenticação segura com OAuth 2.0 e armazenamento de banco de dados na nuvem (Firestore), com criptografia em trânsito (TLS 1.3) e em repouso (AES-256).
  • Vercel Inc.: Hospedagem web e rede de distribuição de conteúdo estático (CDN).

6. Retenção e Segurança dos Dados

Os dados do usuário são mantidos apenas pelo tempo necessário para cumprir a finalidade para a qual foram coletados (ou seja, enquanto a conta estiver ativa no aplicativo para fornecer acesso às suas progressões e estudos musicais).

Adotamos medidas técnicas e administrativas aptas a proteger os dados de acessos não autorizados e de situações acidentais ou ilícitas de destruição, perda, alteração ou vazamento.

7. Direitos do Usuário e Exclusão Completa de Dados

Em conformidade com o Artigo 18 da LGPD e o Artigo 17 do GDPR, você tem o direito garantido de, a qualquer momento e sem custos:

  • Acessar, confirmar e revisar todas as informações associadas à sua conta;
  • Corrigir eventuais dados incompletos ou inexatos;
  • Revogar o acesso da aplicação: Você pode desconectar o Workestra Tools da sua Conta Google instantaneamente acessando a página oficial de segurança do Google: https://myaccount.google.com/permissions;
  • Exclusão definitiva de dados: Solicitar a eliminação imediata de todos os seus dados e progressões armazenados no banco de dados. Para solicitar a exclusão de seus dados, envie uma mensagem para o e-mail oficial: rotozzi09@gmail.com com o assunto "Exclusão de Dados — Workestra Tools". A exclusão definitiva será realizada em até 48 horas úteis com confirmação por e-mail.
